Дополнительные операции

Количество для операций «Резка металла» и «Зачистка швов» автоматически равно числу сварных стыков (детали × концы). Для этих операций единица измерения — шт.; количество пересчитывается при изменении деталей. Для каждой операции установлены примерные значения себестоимости, единицы измерения и наценки. Меняй их при необходимости; обычно достаточно указать количество. Это ориентиры, а не подтверждённые расценки. Для сварки, уже учтённой автоматически, не добавляйте повторную строку без необходимости.
