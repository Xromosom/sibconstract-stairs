ASCII DXF в миллиметрах. Поддерживаются LINE, CIRCLE, ARC, LWPOLYLINE (включая дуговые сегменты). Для закупки листа используется габарит детали, поэтому фигурный раскрой приблизительный.

Учёт остатков металла — оценка стоимости

Разница между закупкой целых листов и стоимостью металла в деталях считается потенциальным складским остатком. Это денежная оценка, а не карта физических обрезков: реальные остатки нужно проверять по раскрою.

Раскрой и закупка металла

Детали одного профиля размещаются по хлыстам стандартной длины. Раскрой приближённый, без учёта зажимов и технологических припусков.

Параметры

Нормы скорости, подготовки, расходников и проценты пока примерные; их необходимо проверить по факту.

Дополнительные операции

Количество резки и зачистки автоматически равно числу сварных стыков; грунтовка и покраска рассчитываются по наружной площади деталей (детали × концы). Для этих операций единица измерения — шт.; количество пересчитывается при изменении деталей. Для каждой операции установлены примерные значения себестоимости, единицы измерения и наценки. Меняй их при необходимости; обычно достаточно указать количество. Это ориентиры, а не подтверждённые расценки. Для сварки, уже учтённой автоматически, не добавляйте повторную строку без необходимости.
