# СИБКОНСТРАКТ — тестовый 3D-конструктор лестниц

Статический демонстрационный проект для GitHub Pages.

- Вращаемая 3D-модель прямой лестницы на центральном косоуре.
- Изменение высоты, длины, ширины и материала ступеней.
- Предварительные геометрические показатели.
- Без серверных функций, CRM, ключей и формы отправки заявок.

Модель — концептуальный эскиз, не рабочая конструкторская документация.
Для 3D используется Three.js через внешний CDN; требуется интернет.

Публикация: Settings → Pages → Deploy from a branch → main → /(root).
